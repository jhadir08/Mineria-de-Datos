Cada carpeta debe contener el laboratorio correspondiente de la semana en formato `.ipynb`.

## Convencion sugerida

Usa nombres claros y ordenables:

```text
Semana_01/lab_semana_01.ipynb
Semana_02/lab_semana_02.ipynb
```

Si el docente pide un nombre especifico para el archivo, conserva ese nombre dentro de la carpeta de la semana.

## Flujo basico

```powershell
git status
git add .
git commit -m "Agregar laboratorio semana 01"
git push origin main
```
